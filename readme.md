# Ultimate 8-Puzzle Solver

A feature-rich, high-performance 8-puzzle game built with React 19, TypeScript, and Tailwind CSS. This application not only provides a classic sliding puzzle experience but also serves as an educational tool for visualizing Artificial Intelligence pathfinding algorithms.

## 🚀 Features

- **Classic Gameplay**: 3x3 grid with tiles 1-8 and a blank space.
- **AI Solvers**: Integrated BFS, DFS, A* (Manhattan Distance), and IDS algorithms.
- **Algorithm Visualization**: Watch the AI solve the puzzle with adjustable replay speeds.
- **Performance Metrics**: Real-time stats for nodes explored, steps taken, and compute time.
- **Responsive Design**: Neumorphic UI that works perfectly on desktop and mobile.
- **Dark Mode**: Toggle between light and dark themes for comfortable play.
- **Persistence**: Best scores and theme preferences saved to local storage.
- **Accessibility**: Support for keyboard controls (WASD/Arrow keys).

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
